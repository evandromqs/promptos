Política de Privacidade

Última atualização: 22 de outubro de 2026
Privacidade da extensão: O PromptOS foi desenvolvido para funcionar 100% no seu navegador. Nós não rastreamos, não coletamos e não armazenamos nenhuma informação pessoal ou conteúdo dos seus prompts em servidores externos.

1. Coleta e Armazenamento de Dados

Todos os seus dados criados na extensão — incluindo títulos de prompts, categorias, modelos com variáveis, contadores locais de uso, imagens de referência, marcações de favoritos e fluxos de trabalho (workflows) — são gravados exclusivamente no seu dispositivo, utilizando a API nativa chrome.storage.local.

O PromptOS não envia a biblioteca a servidores do desenvolvedor e não utiliza telemetria. Ao selecionar a inserção, o texto preparado é colocado no campo de mensagem do ChatGPT. Se você enviar a mensagem, o conteúdo será tratado pelo ChatGPT conforme as políticas desse serviço.

2. Permissões Solicitadas no Chrome (Manifest V3)

Para fornecer suas funcionalidades essenciais, o PromptOS requer as seguintes permissões declaradas em seu manifest.json:

  • storage: Utilizada unicamente para salvar localmente no seu navegador a sua biblioteca de prompts, templates de variáveis, fluxos de trabalho e preferências visuais (tema claro/escuro).
  • scripting e Host Permissions (https://chatgpt.com/* e https://chat.openai.com/*): Utilizadas para permitir a exibição do painel retrátil integrado e transferir o texto do prompt selecionado para a caixa de mensagem do ChatGPT quando você clica em "Inserir no ChatGPT". A extensão não lê o histórico de conversas do seu chat e não envia mensagens de forma autônoma.

3. Compartilhamento com Terceiros

O PromptOS não vende, não aluga, não compartilha e não monetiza nenhum tipo de dado do usuário. Não utilizamos redes de anúncios, rastreadores analíticos ou ferramentas de fingerprinting.

4. Backup, Portabilidade e Exclusão

Você é o único proprietário de todos os prompts e fluxos cadastrados. A qualquer momento, você pode:

  • Exportar Backup: Gerar um arquivo .json completo contendo seus prompts e fluxos de trabalho com um único clique na tela de configurações.
  • Restaurar Backup: Carregar um arquivo de backup previamente salvo para restabelecer seus prompts em qualquer instalação.
  • Exclusão Total: Ao desinstalar a extensão pelo menu do Google Chrome, o Chrome remove o armazenamento local da extensão. Arquivos de backup exportados permanecem onde você os salvou e devem ser excluídos separadamente. Você também pode excluir prompts e fluxos pela interface.

5. Conformidade com a Chrome Web Store

O uso de informações recebidas das APIs do Google pelo PromptOS segue a Política de Dados do Usuário da Chrome Web Store, incluindo os requisitos de Uso Limitado. Os dados são usados apenas para fornecer as funções descritas da extensão.

6. Este site

Este site é hospedado pela Vercel, que pode processar dados técnicos de acesso, como endereço IP e registros de requisições, para fornecer e proteger a hospedagem. O site não inclui analytics, anúncios ou formulários de coleta. Essa hospedagem é separada do armazenamento local da extensão.
